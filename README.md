# My First Addon

A minimal Hello World addon for World of Warcraft Classic Era.

## Install

Copy the `myFirstAddon` folder into your Classic Era `Interface\AddOns` folder. Make sure the folder contains `myFirstAddon.toc` and `core.lua` directly.

In game, enable **My First Addon** on the character selection AddOns screen, then log in or type `/reload`. The chat window will show:

```text
Hello, World!
```
